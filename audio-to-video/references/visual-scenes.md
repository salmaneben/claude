## ليش الفرق مهم
بالفيديو المصوّر، الوجه هو «الراحة»: المشاهد يرتاح عليه بين المشاهد، والرسم ضيف.
بالصوت وحده **ما فيه راحة** — كل إطار لازم يكون فيه شي يستاهل النظر، وإلا المشاهد يحس إنه يسمع بودكاست بخلفية ملوّنة ويسحب.
فالمقاييس تتغيّر:

| | فيديو بوجه (الأساس) | صوت فقط (هنا) |
|---|---|---|
| التغطية | مشهد كل ١٥ ث على الأقل | **الشاشة مغطّاة ١٠٠٪** — مشهد يسلّم للي بعده بلا فجوة (≤ ٠٫٣٥ ث) |
| الإيقاع | الوجه يحمل الإيقاع | **نبضة بصرية كل ٢–٤ ث** (عنصر يدخل، رقم يتغيّر، الكاميرا تتحرك) |
| تبديل المشهد | حسب الفكرة | **مشهد جديد كل ٥–٨ ث** تقريباً — أقل عدد = المدة ÷ ٨ (دقيقة ← ٨ مشاهد على الأقل) |
| الصيغ | FULL · CARD · SIDE · NONE | **NONE دائماً** — `a3_stage.py` يكتبه، لا تكتب stage.json بيدك |
| حدّ «فوق الشعر» (y ≤ 420) | إلزامي | ما فيه شعر — المساحة كلها لك (ضمن المنطقة الآمنة تحت) |

## المساحة — اللوحة كاملة 1080×1920
| المنطقة | الاستعمال |
|---|---|
| y 0 → 160 | لا نص (واجهة انستقرام وتيك توك فوق) — خلفية ورسم زخرفي بس |
| **y 160 → 1200** | **مسرح الرسم الرئيسي** — العنوان والعنصر البطل هنا |
| y 1200 → 1470 | الكابشن (كرت بسطرين، حافته السفلى 1460) — لا تحط نصاً مهماً تحته |
| y 1500 → 1920 | الشارة (1546 يسار) وواجهة المنصّة — خلفية وامتداد صور بس |
| x > 900 من y 1100 إلى 1750 | أزرار الإعجاب والتعليق — لا نص |

الصورة ملء الشاشة (`full-bleed`) مسموحة وتمتد تحت الكابشن عادي — بس **ما فيها نص ولا وجه مهم** بمنطقة الكابشن.
ولو مشهد يحتاج المساحة السفلى لحظة (رقم ضخم، رسم بياني)، ارفع الكابشن لحظتها بـ`<work>/capmove.json` ← `[[من, إلى, bottom]]`.

## الكاميرا الافتراضية — اللي يربط المقطع
بدون وجه، المشاهد المتفرقة تحس «شرائح بوربوينت». الحل المعتمد: **عالم واحد** (`styles/IDEAS.md` بالأساس)
مبني كلوحة كبيرة، و«كاميرا» تتحرك بين أجزائه — كل مشهد ركن من نفس العالم:
```tsx
import {eio} from './util';   // p · ease · back · lerp · rgba مستوردة أصلاً بالقالب — eio لا
/* غلاف كاميرا: يحرّك العالم كله — الانتقال بين مشهدين = حركة كاميرا لا تلاشي */
const Cam = ({t, keys, children}:{t:number; keys:[number,number,number,number][]; children:React.ReactNode}) => {
  // keys: [الوقت, x, y, scale] — بين كل نقطتين حركة ناعمة
  let i = keys.findIndex(k => k[0] > t); if (i < 0) i = keys.length; const a = keys[Math.max(0,i-1)], b = keys[Math.min(i, keys.length-1)];
  const k = b[0] === a[0] ? 1 : eio(Math.min(1, (t-a[0]) / Math.min(0.8, b[0]-a[0])));
  return <div style={{position:'absolute', inset:0, transform:`translate(${-lerp(a[1],b[1],k)}px,${-lerp(a[2],b[2],k)}px) scale(${lerp(a[3],b[3],k)})`, transformOrigin:'0 0'}}>{children}</div>;
};
```
استعملها لنصف المقطع على الأقل. والمشاهد اللي «تقطع» (صورة كاملة، رقم ضخم) تكسر الرتابة بينها.

## كتابة المشهد — بصيغة تفهمها الفواحص
فواحص الأساس (19 · 16 · 13) تقرأ `Scenes.tsx` بنمط ثابت — التزم فيه وإلا تقول «سليم» وهي ما فحصت شي:
```tsx
const Hook = ({t}:{t:number}) => {
  const A=0.00, B=4.80;                       // ← بأول ٦ أسطر، بهالشكل بالضبط
  if (t < A || t > B) return null;
  const k = p(t, 0.00, 0.45), out = p(t, 4.50, 4.80);   // p(t, رقم, رقم) — الفاحص يحسب الحركة منها
  ...
};
export const Scenes = ({t}:{t:number}) => (<>
  <Hook t={t} />
  ...
</>);
```
- **A و B من `caps.json`**: المشهد يبدأ مع أول كلمة من جملته وينتهي مع آخرها (أو مع بداية المشهد التالي).
- **التسليم بلا فجوة**: `A` لكل مشهد = `B` للي قبله (أو تداخل ٠٫٢–٠٫٣ ث لعبور ناعم). أول مشهد يبدأ من `0.00`.
- **لا جمود > ٢٫٥ ث**: أي مشهد أطول من كذا يحتاج حركة ثانية بنصّه (عنصر جديد مع كلمة، رقم يتغيّر، تقريب بطيء بـ`p(t,…)`).
- الصور بـ`<Img>` من ريموشن، **مو** `backgroundImage` — الأخيرة تطلع ومضة بيضاء (فاحص 25 يمسكها).
- الألوان والخط من `T` (الثيم) فقط. الوزن هو التدرّج، عائلة خط وحدة.

## الصور — حملها أثقل هنا
بلا وجه، الصورة هي «الإنسان» بالمقطع. حسب تفضيلاته بـ`profile.json`:
- **يولّد صوراً بنموذج ذكاء اصطناعي** ← اتبع `references/generated-images.md` بالأساس، ونسبة معقولة: صورة لكل ٢–٣ مشاهد.
  اطلب المشهد الكامل بنسبة 9:16 للصور الكاملة، والخلفية السادة للي تنقص وتتركّب.
- **صور مجانية** ← من مصادر موثوقة، ونفس القيود (القاعدة ١١ بالأساس) على كل إطار.
- **ولا صور** ← الطباعة الحركية والرسوم والأيقونات تشيل المقطع — زِد كثافة الحركة بدلها.
