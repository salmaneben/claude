# من الصوت إلى الفيديو — بلا وجه

المستخدم يعطيك **صوتاً فقط**، وأنت تسلّمه **فيديو كاملاً**: كابشن متزامن + مشاهد وموشن قرافيكس وصور تملأ الشاشة طول المقطع + مؤثرات صوتية. المخرَج MP4 جاهز للنشر، ومعه ملف ترجمة ونص.

## الفكرة — ليش هالمهارة صغيرة
كل الأدوات الثقيلة موجودة بمهارة **video-editor-bassam** (القص، التفريغ، الكابشن، محرّك الرسم، المؤثرات، المعايرة، الفواحص)، ومصمّمة لفيديو فيه وجه.
هذه المهارة تستعملها كما هي وتغيّر ثلاثة أشياء بس:
1. **المصدر**: `a1_prepare.py` يبني `src.mov` من إطار ساكن + صوته كما هو — فكل أدوات الأساس تشتغل بلا تعديل.
2. **النافذة**: `a3_stage.py` يخفي نافذة الفيديو طول المقطع (`NONE`) — الشاشة كلها للرسم، والإطار الساكن ما يظهر أبداً.
3. **المشاهد والفواحص**: مقاييس مقطع بلا وجه (`references/visual-scenes.md`)، و`a4_preflight.py` بدل فاحص الأساس — يتخطّى فواحص الوجه واللون والنظرة لأنها ما تنطبق.

**كل قواعد الأساس تبقى سارية** — أسلوبك مع المستخدم، الخطوط الحمراء، صوته كما دخل، التسليم. اقرأ `SKILL.md` بالأساس مرة بأول الشغل.

## الخطوة 0 — لقّ الأساس وجهّز الجهاز
```bash
BASE="$(python3 scripts/_base.py)"      # مسار video-editor-bassam — كل أوامر <BASE> تحت منه
bash "$BASE/scripts/00_setup.sh"         # نفس فحص الأساس (أدوات كشف الوجه ما نحتاجها هنا)
```
- ما لقاها؟ قل له بجملة: «هذه المهارة تحتاج مهارة المونتاج الأساسية (video-editor-bassam) مثبّتة عندك» ووقف.
- ناقص أدوات؟ اتبع أسلوب الأساس بالضبط: جملة وحدة وش بتنزّل وكم ياخذ، وبعد موافقته `--install`.

## الخطوة 0.5 — أسئلة البداية
**ما فيه `profile.json` بمجلد بياناته؟** ← `<BASE>/references/onboarding.md` كامل، **ما عدا** السؤال ٦ (طريقة التصوير) والشق الخاص بالصورة من السؤال ١٠ — ما فيه تصوير.
**فيه؟** ← ثلاثة أسئلة، **سؤال واحد بكل رسالة**:
1. **وش تبي بهالمقطع؟**
   - **كابشن على خلفية حيّة** — كلامه مكتوب متزامن فوق خلفية بألوانه، سريع (`{"mode":"quick"}`).
   - **مونتاج كامل** — مشاهد وموشن قرافيكس وصور تغطي المقطع كله (الافتراضي).
2. **السكتات:** «أشيل الوقفات الطويلة من صوتك، ولا الصوت جاهز وتبيه بإيقاعه؟» — صوت مولّد أو فيه موسيقى ← بلا قص.
3. **«عندك نص الكلام مكتوب؟»** — لو الصوت مولّد من نص أو مقروء من سكربت، النص يخلّي الكابشن مطابقاً ١٠٠٪.

ونفس أسلوبه المعتاد ولا شي مختلف؟ — من `prefs` بملفه، لا تسأل لو واضح.

## الخطوة 1 — مجلد الشغل والهوية
```bash
python3 -c "import sys;sys.path.insert(0,'$BASE/scripts');import _paths;_paths.ensure();print(_paths.data('projects'))"
```
أنشئ `<projects>/<اسم المقطع>/` = `<work>`، وانسخ له (مثل الأساس):
- `profile.json` ← `<work>/theme.json` · الشعار ← `<work>/logo.png` · `<work>/style.json` ← `{"style": "<أسلوبه>"}`.
- لو اختار «كابشن على خلفية حيّة»: `<work>/mode.json` ← `{"mode": "quick"}`.

## الخطوة 2 — خذ الصوت
```bash
python3 scripts/a1_prepare.py "<ملفه الصوتي>" <work>
```
يقبل mp3 · wav · m4a · aac · ogg · flac (أو فيديو ويأخذ صوته). يكتب `src.mov` و`audio_only.json`، ويضبط `noZoom` بالثيم.
رابط قوقل درايف؟ نفس طريقة الأساس (الخطوة ٢ هناك) ثم مرّر الملف المنزّل.

**وضع «كابشن على خلفية حيّة»:** تخطَّ ٦٫٥ و٧ (المشاهد) — كمّل من ٨ (الأصوات اختيارية) ثم ٩.

## الخطوة 6.5 — صور ومقاطع حقيقية حسب حاجة كل لحظة (من الأساس)
بلا وجه، الصورة الحقيقية هي «الإنسان» بالمقطع — فهالخطوة هنا أهم منها بالأساس. نفس الأداة المشتركة:
```bash
python3 "$BASE/scripts/26_pexels.py" <work> plan       # كلامه بتوقيته + قالب pexels.json
python3 "$BASE/scripts/26_pexels.py" <work> fetch      # ٣ مرشّحين لكل لحظة
python3 "$BASE/scripts/26_pexels.py" <work> sheet      # ورقة مرشّحين — افحص قيوده
python3 "$BASE/scripts/26_pexels.py" <work> pick <لحظة> <رقم> [--dur 3]   # ← <work>/assets/px_<لحظة>.*
```
التفاصيل والقواعد: الخطوة ٦٫٥ والقاعدة ١١٩ بالأساس. `kind` لكل لحظة حسب حاجتها (صورة · مقطع · الاثنين)، وتفضيله `stockMedia` يغلب.

## الخطوة 7 — المشاهد ← أهم خطوة وأكبر فرق
**اقرأ `references/visual-scenes.md` كاملاً**، ومعه `<BASE>/references/scenes.md` ودليل أسلوبه و`<BASE>/references/rules.md` (مرة وحدة).
الخلاصة: بلا وجه **ما فيه راحة للعين** — الشاشة مغطّاة كلها، نبضة بصرية كل ٢–٤ ث، مشهد جديد كل ٥–٨ ث، وعالم واحد يربط المقطع.
```bash
bash "$BASE/scripts/04b_remotion.sh" <work> setup     # أول مرة (~500 ميقا) — قل له قبلها
bash "$BASE/scripts/04b_remotion.sh" <work> studio    # http://localhost:3000 — يشوف المقطع حيّاً
```
0. **الهوك أولاً** — `<BASE>/references/hook.md` و`python3 "$BASE/scripts/27_hook.py" <work> plan`: ٢–٣ صيغ يختار منها ← `hook.json` ← أول مشهد.
   بلا وجه الهوك يشيل حمل أكبر: `visual` أو `number` أو `question` بحركة قوية (`behind` ممنوع — ما فيه شخص).
1. اعرض عليه ٢–٣ «عوالم» للمقطع (`<BASE>/styles/IDEAS.md`) قبل ما تبني.
2. اكتب المشاهد بـ`<work>/Scenes.tsx` بالصيغة اللي يشرحها المرجع (الفواحص تعتمد عليها).
3. `python3 scripts/a3_stage.py <work>` — جدول النوافذ (**بدل** `18_stage_from_scenes.py` — ذاك يرجّع الإطار الساكن مكان الوجه).
4. الصور: حسب `prefs` بملفه — `<BASE>/references/generated-images.md` لو يولّد صوراً.
5. لا تكرّر آلية من آخر مقطعين (`LEDGER.md` و`13_repeat_check.js` بالأساس).

## الخطوة 8 — المؤثرات الصوتية

- ⛔ **لا تستعمل `22_preflight.py` من الأساس** — يشغّل 18 فيرجع الإطار الساكن، ويفحص وجهاً ونظرة ما هي موجودة.
- **رسالة «⛔ اللون تغيّر» بعد الرندر متوقّعة هنا وتُتجاهل**: فاحص اللون (21) يقارن الناتج بالفيديو المصوّر، وهنا الإطار الساكن مخفي عمداً تحت الرسم. فاحص الصوت (20) هو اللي يهمّ — لازم ينجح.
- عاين قبل الرندر الكامل: `render-test` لمدى قصير و`scripts/a5_sheet.sh` لورقة لقطات منه — واعرضها عليه.
