# الهوك — أول ٣ ثواني تقرّر كل شي

> أغلب المشاهدين يقرّرون بأول ثانية أو ثانيتين: يكمّلون ولا يسحبون. المقطع الممتاز بهوك ضعيف ما أحد يشوفه.
> **الهوك يتصمّم قبل باقي المشاهد** — هو أهم مشهد بالمقطع، مو أول واحد بالترتيب وبس.
> الأداة: `scripts/27_hook.py` (مشتركة بين المهارتين).

## الخطوات
```bash
python3 scripts/27_hook.py <work> plan          # أول الجمل بتوقيتها + الأنماط + آخر أنماطه
```
1. **اقرأ أول جملتين، وأقوى جملة بالمقطع كله.** الهوك غالباً أول جملة — بس لو أقوى جملة بالنص، نمط `story` يقدّمها.
2. **اعرض عليه ٢–٣ صيغ** (سؤال واحد، أمثلة يختار منها): النمط + النص اللي ينكتب + وش يظهر على الشاشة. مثال:
   - «سؤال: **ليش ٩٠٪ يفشلون بأول سنة؟** بخط ضخم، وكل كلمة تنزل مع نطقها»
   - «رقم: **٩٠٪** يعدّ من صفر وينصبغ أحمر عند (يفشلون)»
   - «صورة: مقطع حقيقي لمكتب فاضي ملء الشاشة، وفوقه (بأول سنة)»
3. **اكتب `<work>/hook.json`:**
   ```json
   {"pattern": "number", "text": "٩٠٪ يفشلون بأول سنة", "s": 0.0, "e": 2.4,
    "visual": "px_hook.mp4", "cover_t": 1.2}
   ```
   `visual` اختياري (صورة أو مقطع من `assets/`) · `cover_t` اختياري (لحظة الغلاف — وإلا يختار أوضح إطار).
4. **ابنِ الهوك أول مشهد بـ`Scenes.tsx`** — ونافذته بالجدول من 0.
5. الفاحص: `27_hook.py <work> check` قبل الرندر، و`--out <فيديو>` بعده (الاثنان داخل الفاحص الشامل).

## الأنماط
| النمط | الشكل | يناسب |
|---|---|---|
| `question` | سؤال صادم بخط ضخم يملأ الشاشة، كلمة كلمة مع نطقه | الشرح والمعلومة |
| `number` | رقم ضخم يعدّ قدامه، وينصبغ لون التمييز عند كلمته | الإحصاءات والمال |
| `visual` | صورة أو مقطع حقيقي ملء الشاشة بتقريب **سريع** (٨–١٢٪ بثانيتين) + كلمة فوقه | الأماكن والقصص والمنتجات |
| `promise` | النتيجة أولاً («بـ٣٠ ثانية بتعرف…») مع عدّاد أو شريط تقدّم | النصائح والخطوات |
| `contrast` | الشاشة تنقسم: قبل/بعد · خطأ/صح، والفاصل يتحرك | المقارنات |
| `myth` | الجملة الشائعة تنكتب ثم تنشطب بخط أحمر | «الكل يقول…» |
| `story` | أقوى لحظة بالقصة أولاً (٢–٣ ث) ثم قطع حاد للبداية | القصص الشخصية |
| `behind` | الكلمة ورا الشخص (`11_behind_text.js`) | **فيديو فيه وجه بس** |

## القواعد
1. **شي يبان قبل 0.3 ث، وأول كابشن قبل 0.5 ث.** ⛔ لا تلاشي من الأسود، ولا شعار، ولا «السلام عليكم» على شاشة فاضية.
2. **حدث بكل ثانية من أول ٣** — كلمة تدخل · قطع · رقم يتغيّر · صورة جديدة. الفاحص يقيسها بالصورة نفسها.
3. **الخط ضخم:** `hookSize` بالثيم (90 افتراضياً) فما فوق — ويقرأ بلا صوت (أغلبهم يشوفون والصوت مطفي).
4. **الكلام المهم بالمنطقة الآمنة** (`scenes.md`) **وبين y 240 و1680** — عشان يبان كاملاً بالغلاف بشبكة حسابه (3:4).
5. **صوت `hookrise`** (أو صوت من مكتبته) يبدأ مع أول إطار — بس لو المؤثرات مفعّلة عنده.
6. **⛔ لا تكرّر نمط آخر مقطع** — `hooks.json` بمجلد بياناته يتذكّر، والفاحص يرفض التكرار.
7. **الهوك وعد — المقطع يوفي فيه.** لا تكتب سؤالاً ما يجاوبه كلامه، ولا رقماً ما قاله (القاعدة ٦: لا تنسب له كلاماً).
8. **مقطع بلا وجه (`audio-to-video`):** الهوك يشيل حمل أكبر — `visual` أو `number` أو `question` بحركة قوية؛ `behind` ممنوع.

## صورة الغلاف
```bash
python3 scripts/27_hook.py <work> cover <work>/ad-master.mp4 [--t 1.2]   # → <work>/cover.jpg (1080×1920)
```
- تُرسم من لقطة الهوك نفسها بمشروع ريموشن **بلا كرت الكابشن** (نص جملة مقطوعة تحت الغلاف يخرّبه).
  ما فيه مشروع جاهز؟ ينزل لإطار من الفيديو وينبّه إن فيه كابشن. متصفح محلي: `REMOTION_BROWSER_EXECUTABLE=<المسار>`.
- اعرضها عليه، وسلّمها مع الفيديو: `<اسم المقطع>-غلاف.jpg`.
- لو ما عجبته: `--t` بوقت ثاني، أو `cover_t` بـ`hook.json`.

## بعد التسليم
```bash
python3 scripts/27_hook.py <work> log --name "<اسم المقطع>"    # يسجّل النمط — المقطع الجاي ما يكرّره
```
